# Envi DIY POS — Dual-Screen Retail Edition

ระบบ POS สำหรับร้าน/บูธ Envi DIY ใช้ Next.js App Router, TypeScript, Tailwind CSS, Neon PostgreSQL, PromptPay QR และ Vercel Blob

## เริ่มต้นใช้งาน
1. สร้าง Neon database แล้วรัน `schema.sql`
2. ตั้งค่า Environment Variables ใน Vercel: `DATABASE_URL`, `PROMPTPAY_ID`
3. สร้าง Vercel Blob store และเชื่อมกับโปรเจกต์ (จะสร้าง `BLOB_READ_WRITE_TOKEN` ให้)
4. ตั้ง `BLOB_UPLOAD_SECRET` เป็นรหัสลับที่ผู้ดูแลจะใช้ในหน้าจัดการสินค้า
5. เปิด `/products` เพื่อเพิ่มสินค้า รูปภาพ และวิดีโอแนะนำหน้าร้าน
6. เปิด `/cashier` และ `/display` บนอุปกรณ์คนละเครื่อง

## จอแคชเชียร์และจอลูกค้า
- แคชเชียร์สร้างรหัสเชื่อมต่อหนึ่งครั้ง แล้วจอลูกค้าสแกน QR เพื่อจับคู่
- รหัสเชื่อมต่อถูกเก็บไว้บนอุปกรณ์ทั้งสองฝั่ง จึงไม่ต้องสร้างใหม่ทุกบิล
- แคชเชียร์กด “เลิกเชื่อมต่อ” เพื่อปิด session; จอลูกค้าจะล้างรหัสเดิมเมื่อ poll รอบถัดไป
- ระหว่างรอขาย จอลูกค้าแสดงวิดีโอและแกลเลอรีสินค้า
- เมื่อกด PromptPay ระบบสร้าง QR จาก `PROMPTPAY_ID` พร้อมยอดชำระของบิลนั้นโดยตรง ไม่ใช้ static QR
- เมื่อแคชเชียร์ตรวจสอบยอดโอนในแอปธนาคารแล้วกดยืนยัน จอลูกค้าแสดงหน้าขอบคุณ จากนั้นกลับสู่หน้าสินค้าอัตโนมัติ
- QR เป็นคำขอชำระเงิน ไม่ใช่หลักฐานว่าเงินเข้าบัญชี ต้องตรวจสอบรายการเงินจริงก่อนยืนยัน

## สื่อสินค้า
- รูปภาพสินค้า: JPG, PNG, WebP, AVIF
- วิดีโอหน้าร้าน: MP4 หรือ WebM ไม่เกิน 100 MB
- สื่อถูกเก็บใน Vercel Blob; ใช้ `BLOB_UPLOAD_SECRET` เพื่ออนุญาตการอัปโหลดจากหน้า Admin

## ความปลอดภัย
เวอร์ชันนี้ยังต้องเพิ่ม Authentication/Role-based access และจำกัด API สำหรับผู้ดูแล/แคชเชียร์ก่อนเปิดใช้งานสาธารณะ การอัปโหลดมี shared secret แต่ API จัดการสินค้าและการขายส่วนอื่นยังต้องมีระบบสิทธิ์แยกต่างหาก
